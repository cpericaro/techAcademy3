# Projeto techAcademy3 
## Rubrica

## Objetivo:
Este projeto tem como objetivo aplicar, de forma prática, os conhecimentos adquiridos ao longo do curso, desenvolvendo um pequeno sistema completo em PHP com orientação a objetos, utilizando banco de dados MySQL, seguindo boas práticas de estruturação de código, modelagem de dados e publicação em repositórios públicos.

## Enunciado
Desenvolver um software de pequeno porte, com tema livre, desde que atenda a um propósito real ou simulado (ex: sistema de reservas, gerenciamento de tarefas, controle de estoque, biblioteca digital, etc.).

- O sistema deverá:
Ser desenvolvido utilizando PHP orientado a objetos.
Utilizar MySQL como banco de dados.
Ser estruturado seguindo boas práticas de arquitetura de software, preferencialmente utilizando o padrão MVC (Model-View-Controller).
Fazer uso do Composer para incluir ao menos uma biblioteca externa.
Ser publicado em um repositório público no GitHub (um por dupla).
Ser funcional e coerente com o propósito proposto.
Ser capaz de lidar com erros e exceções de maneira adequada, sem exibir mensagens de erro do PHP diretamente ao usuário.

## Requisitos Técnicos:
- Modelagem:
Entregar o diagrama entidade-relacionamento (DER) do banco de dados.
Utilizar no mínimo 3 tabelas.
Todas as tabelas devem ter chave primária definida.
O projeto deve ter ao menos uma chave estrangeira corretamente aplicada.
Utilizar ao menos uma enumeração no código (por exemplo: status de pedido, tipo de usuário, etc.).

- Orientação a Objetos:
O projeto deve aplicar os princípios de encapsulamento, utilizando modificadores de acesso corretamente.
As entidades do sistema devem estar bem definidas e refletidas em classes.
O código deve ser modularizado e reaproveitável.

- Arquitetura:
Separar corretamente as responsabilidades entre classes e arquivos (por exemplo: Models, Controllers, Views).
É altamente recomendada a utilização de uma estrutura MVC.
O aluno deve ser capaz de explicar claramente a arquitetura adotada e justificar as decisões tomadas.

- Funcionalidade:
O sistema deve ser navegável e permitir interações básicas de acordo com o propósito proposto (ex: cadastrar, listar, editar e excluir registros).
Deve ser possível utilizar o sistema normalmente, sem erros de execução visíveis.

## Entrega:
- O projeto deverá ser publicado no GitHub com um README.md contendo:
Nome do projeto
Descrição do propósito do sistema
Instruções de instalação e execução
Nome dos integrantes da dupla
Link para o DER
