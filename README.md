# Projeto techAcademy3 

## Nome do projeto
**Plantera - Gestão Escolar**

## Descrição do propósito do sistema
    Plantera tem como intuito operar na mesma lógica de um sistema escolar, o intuíto dele é baseado numa dor real onde a solução já foi desenvolvida e aplicada
    Cuja se baseia em, separar perfis de professores e pais, disponibilizando area de pagamentos, feedbacks individuais em cada aluno(a), visualização de presença, conteúdo abordado no dia e cronograma de ensino
