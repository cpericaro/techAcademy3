# Projeto techAcademy3 

## Nome do projeto
**Plantera - Community Forum**

## Descrição do propósito do sistema
    Plantera tem como intuito operar na mesma lógica de um forum publico, algo parecido como o reddit ou stackoverflow, onde o mesmo pode haver diferentes tópicos ou comunidades e atender diferentes tipos de conteúdo, voltado ao compartilhamento de informações ou discussões orientadas
